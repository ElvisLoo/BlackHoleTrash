# Black Hole Trash v1.0.0

首个可公开下载的 Windows x64 安装版本。

## 主要功能

- 小巧、可拖动的桌面黑洞；
- Schwarzschild / Kerr 实时引力透镜与吸积盘；
- Windows Explorer OLE 文件、文件夹和多项目拖放；
- 使用 `IFileOperation + FOFX_RECYCLEONDELETE` 送入回收站；
- 不包含永久删除后备路径；
- DX12 与 D3D11 → D3D12 共享纹理零拷贝桌面捕获；
- 多显示器、托盘和外观预设。

## 安装

下载并运行 `BlackHoleTrash-Setup-x64.exe`。安装程序按当前用户安装，不需要管理员权限，并提供开始菜单快捷方式、可选桌面快捷方式和标准卸载入口。

安装包尚未进行代码签名，Windows SmartScreen 可能显示安全提醒。可使用同时发布的 `.sha256` 文件核对下载完整性。
