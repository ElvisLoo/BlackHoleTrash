# Black Hole Trash v1.1.0

本版本为 Windows 鼠标增加黑洞引力与螺旋吸收效果。

## 新功能

- 光标进入黑洞外圈后产生最高 10% 的渐进阻力；
- 从黄圈附近开始短暂绕转，并在约 160 ms 内带着多层残影收进中心；
- 快速向外甩动可立即脱离引力场，不会锁死光标；
- 系统光标在吸收后最多隐藏 150 ms，并在下一次物理移动时立即恢复；
- 跨显示器轨迹连续，拖动黑洞本体时暂停吸附；
- Explorer 文件拖入期间保持吸附，原有回收站安全校验与
  `IFileOperation + FOFX_RECYCLEONDELETE` 路径不变。

## 安装

下载并运行 `BlackHoleTrash-Setup-x64.exe`。安装程序按当前用户安装，
不需要管理员权限，并提供开始菜单快捷方式、可选桌面快捷方式和标准卸载入口。

安装包尚未进行代码签名，Windows SmartScreen 可能显示安全提醒。可使用同时发布的
`.sha256` 文件核对下载完整性。
