# Black Hole Trash v1.2.0

本版本增加吞噬成长、中文托盘和明确的帧率档位。

## 新功能

- 黑洞现在有六档尺寸，吞噬数量达到 `0 / 1 / 3 / 5 / 10 / 20` 个时逐级成长；
- 前五档为初始尺寸的 `1.00 / 1.25 / 1.50 / 1.75 / 2.00 倍`，第六档达到 `4.00 倍`；
- 文件拖放一次跨越多个阈值时会直接进入对应档位，吞噬计数最多记录 20 个；
- 大小、速度、帧率、屏幕保护、旋转、位置、显示器和退出等托盘菜单完成中文化；
- 托盘帧率只保留 `30 帧` 和 `60 帧`；
- 配置中的 `fps` 只接受 `30` 或 `60`，缺失、`0`、无效值和其他数值回退到 `60`；
- 移除无限帧渲染分支，并保持配置热重载与托盘选中状态同步。

## 安装

下载并运行 `BlackHoleTrash-Setup-x64.exe`。安装程序按当前用户安装，不需要管理员权限，并提供开始菜单快捷方式、可选桌面快捷方式和标准卸载入口。

安装包尚未进行代码签名，Windows SmartScreen 可能显示安全提醒。可使用同时发布的 `.sha256` 文件核对下载完整性。

---

This release adds six absorption-driven growth tiers, a Chinese tray menu, and a focused 30/60 FPS policy. The black hole grows at successful-item thresholds of `0 / 1 / 3 / 5 / 10 / 20`, reaching four times its initial size at the final tier. Missing, zero, invalid, and unsupported FPS config values now fall back to 60, and the uncapped rendering branch has been removed.
