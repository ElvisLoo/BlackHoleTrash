# Black Hole Trash v1.2.0

本版本增加吞噬成长、中文托盘和明确的帧率档位。

## 新功能

- 黑洞现在有六档尺寸，吞噬数量达到 `0 / 1 / 3 / 5 / 10 / 20` 个时逐级成长；
- 前五档为初始尺寸的 `1.00 / 1.25 / 1.50 / 1.75 / 2.00 倍`，第六档达到 `4.00 倍`；
- 文件拖放一次跨越多个阈值时会直接进入对应档位，吞噬计数最多记录 20 个；
- 大小、速度、帧率、屏幕保护、旋转、位置、显示器和退出等托盘菜单完成中文化；
- 托盘帧率只保留 `30 帧` 和 `60 帧`；
- 配置中的 `fps` 只接受 `30` 或 `60`，缺失、`0`、无效值和其他数值回退到 `30`；
- 移除无限帧渲染分支，并保持配置热重载与托盘选中状态同步。

## 当前源码桌面更新

- 默认使用桌面感知模式，不开启始终置顶；
- 普通窗口位于黑洞旁边时，黑洞继续显示在露出的桌面区域；窗口与黑洞可见区域相交时自动隐藏，窗口移开、最小化或关闭后恢复；
- 托盘新增“始终置顶”开关，开启后普通窗口不再触发隐藏；
- 两种模式都不创建任务栏按钮，只保留系统托盘入口；
- 原来的 `Ctrl+Shift` 跟随操作改为双击 `Ctrl`，用于把黑洞移动并固定到鼠标位置；
- 默认帧率和无效配置回退值改为 `30 FPS`，仍可选择 `60 FPS`。

## 使用方法

1. 启动程序后无需按 `Win+D`，黑洞会根据普通窗口是否实际覆盖它自动显示或隐藏。
2. 右键系统托盘图标，勾选“始终置顶”可让黑洞保持在普通窗口上方，再次点击可关闭。
3. 将鼠标移到目标位置，在 `350 ms` 内完整按下并松开两次 `Ctrl`，即可移动并固定黑洞。
4. 从托盘的“位置”菜单选择“自动漂移”，可以取消固定位置。
5. 程序没有任务栏按钮，配置和退出操作均从系统托盘进入。

## 安装

下载并运行 `BlackHoleTrash-Setup-x64.exe`。安装程序按当前用户安装，不需要管理员权限，并提供开始菜单快捷方式、可选桌面快捷方式和标准卸载入口。

安装包尚未进行代码签名，Windows SmartScreen 可能显示安全提醒。可使用同时发布的 `.sha256` 文件核对下载完整性。

This release adds six absorption-driven growth tiers, a Chinese tray menu, and a focused 30/60 FPS policy. The black hole grows at successful-item thresholds of `0 / 1 / 3 / 5 / 10 / 20`, reaching four times its initial size at the final tier. Missing, zero, invalid, and unsupported FPS config values now fall back to 30, and the uncapped rendering branch has been removed.

The current source also adds desktop-aware visibility by default, an optional always-on-top tray toggle, permanent tray-only presence, double-`Ctrl` pointer placement, and a 30 FPS default. A normal window beside the hole leaves it visible; intersecting the visible hole area hides it until that window moves away, minimizes, or closes. No `Win+D` press is required. Use the Chinese tray item `始终置顶` to bypass automatic hiding, and double-tap `Ctrl` within 350 ms to move and pin the hole at the pointer.
