# Black Hole Trash v1.3.0

本版本让黑洞真正成为桌面对象：默认只在露出的桌面区域显示，需要时也可以从托盘开启始终置顶。程序始终只驻留在系统托盘，不再占用任务栏窗口。

## 新功能

- **桌面感知显示**：默认不置顶。普通窗口没有碰到黑洞的圆形可见区域时，黑洞继续显示在旁边露出的桌面；窗口与该区域相交时自动隐藏，窗口移开、最小化或关闭后自动恢复。
- **始终置顶开关**：右键托盘图标并勾选“始终置顶”，即可让黑洞保持在普通窗口上方；取消勾选后立即恢复桌面感知模式。
- **仅驻留托盘**：无论是否开启始终置顶，程序都不会创建任务栏按钮，设置和退出入口统一保留在系统托盘。
- **双击 `Ctrl` 放置**：移除原来的 `Ctrl+Shift` 跟随操作。在 `350 ms` 内完整按下并松开两次 `Ctrl`，黑洞会移动并固定到当前鼠标位置。长按、组合键和中间按下其他键不会误触发。
- **默认 30 FPS**：首次启动、未配置帧率或配置值无效时使用 `30 FPS`，仍可从托盘切换为 `60 FPS`。

## 稳定性

- 显示和隐藏前后都会重新验证 Windows 任务栏排除样式，避免任务栏按钮短暂出现；
- 忽略 Shell、DWM cloaked 和工具型覆盖窗口，减少透明悬浮层造成的遮挡误判；
- 黑洞隐藏时同步停用渲染、文件拖放入口和鼠标引力，避免不可见状态仍拦截交互；
- 遮挡状态每 `100 ms` 更新，普通窗口移开后无需按 `Win+D` 即可自动恢复。

## 使用方法

1. 安装并启动 Black Hole Trash。程序不会显示任务栏按钮，请从系统托盘进入设置。
2. 默认模式下，把普通窗口放在黑洞旁边不会影响黑洞；窗口盖到黑洞时会自动隐藏，移开后恢复。
3. 右键托盘图标，点击“始终置顶”可切换覆盖模式。
4. 将鼠标移到目标位置，在 `350 ms` 内完整按下并松开两次 `Ctrl`，即可移动并固定黑洞。
5. 从托盘的“位置”菜单选择“自动漂移”，可以取消固定位置。

## 安装

下载并运行 `BlackHoleTrash-Setup-x64.exe`。安装程序按当前用户安装，不需要管理员权限，并提供开始菜单快捷方式、可选桌面快捷方式和标准卸载入口。

安装包尚未进行代码签名，Windows SmartScreen 可能显示安全提醒。可使用同时发布的 `.sha256` 文件核对下载完整性。

---

This release makes the black hole behave like a real desktop object. Desktop-aware visibility is now the default, always-on-top is optional from the tray, and the app never creates a taskbar button. A normal window beside the hole leaves it visible; intersecting the visible circular area hides it until the window moves away, minimizes, or closes. No `Win+D` press is required.

The old `Ctrl+Shift` placement gesture is replaced by a clean double-`Ctrl` gesture within 350 ms. The default and invalid-value FPS fallback is now 30, while 60 FPS remains available. Visibility transitions reapply native taskbar exclusion, and hidden mode disables rendering, file drops, and cursor gravity.

Download `BlackHoleTrash-Setup-x64.exe`. The per-user installer requires no administrator privileges. It is unsigned, so Windows SmartScreen may display a warning; use the accompanying `.sha256` file to verify the download.
