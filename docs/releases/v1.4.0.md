# Black Hole Trash v1.4.0

本版本让黑洞在吞噬和旋转时真正动起来，同时禁止会破坏资源管理器拖放的管理员权限启动方式。

## 新功能

- **吞噬喷流与冲击光波**：文件成功进入 Windows 回收站后，黑洞会播放约 `900 ms` 的双向能量喷流、中心闪光和向外扩散的冲击光环。一次吞噬的物品越多，能量越强，并在 `20` 个物品时封顶。
- **可见持续旋转**：托盘中的“中速”“高速”和“极限”旋转现在会持续带动透镜背景与吸积盘纹理，速度逐级提升，旋转方向跟随当前吸积盘预设。选择“关闭”时保持静止，不增加原有静态路径的开销。
- **管理员权限启动拦截**：Black Hole Trash 不需要管理员权限。检测到提权启动时，程序会弹窗说明 Windows UIPI 会阻止普通权限的资源管理器向它拖放文件，然后直接停止启动，并提示使用普通双击或开始菜单打开。

## 稳定性

- 旋转相位按实际帧间隔累计，暂停或休眠恢复后的单次时间差会被限制，避免画面突然跳转；
- 成功回收后才触发吞噬效果，失败或取消的操作不会播放成功反馈；
- 批量吞噬强度使用平滑的对数增长，并设置上限，避免效果失控；
- 关闭旋转时，已经累计的相位不会继续影响画面。

## 安装

下载并运行 `BlackHoleTrash-Setup-x64.exe`。安装程序按当前用户安装，不需要管理员权限，并提供开始菜单快捷方式、可选桌面快捷方式和标准卸载入口。

安装包尚未进行代码签名，Windows SmartScreen 可能显示安全提醒。可使用同时发布的 `.sha256` 文件核对下载完整性。

---

This release makes both absorption and spin visibly dynamic while blocking administrator-mode startup, which would break Explorer drag-and-drop through Windows UIPI.

After a successful Recycle Bin operation, the hole emits about 900 ms of bipolar energy jets, a central flash, and an expanding shockwave. Larger batches produce more energy, capped at 20 items. Medium, High, and Extreme spin now continuously rotate the lensed background and accretion-disk texture, while Off remains static on the existing low-cost path.

Download `BlackHoleTrash-Setup-x64.exe`. The per-user installer requires no administrator privileges. It is unsigned, so Windows SmartScreen may display a warning; use the accompanying `.sha256` file to verify the download.
