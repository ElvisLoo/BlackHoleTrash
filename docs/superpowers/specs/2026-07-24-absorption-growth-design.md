# 吞噬成长与中文托盘设计

## 目标

黑洞在每次启动时从桌面图标大小开始。成功回收的顶层文件和文件夹按本次运行累计；累计数量达到 `1`、`3`、`5`、`10` 时，黑洞依次切换到基础尺寸的 `1.25`、`1.50`、`1.75`、`2.00` 倍。累计数量和尺寸成长状态在退出后不保存。

## 五档尺寸

尺寸只有以下五档，渲染、托盘和配置共同使用同一张档位表：

| 档位 | 累计吞噬数 | 相对图标尺寸 |
| --- | ---: | ---: |
| 图标大小 | 0 | 1.00 倍 |
| 成长一档 | 1 | 1.25 倍 |
| 成长二档 | 3 | 1.50 倍 |
| 成长三档 | 5 | 1.75 倍 |
| 最大尺寸 | 10 | 2.00 倍 |

基础尺寸沿用当前最小半径 `0.011`，所以五档半径分别为 `0.011`、`0.01375`、`0.0165`、`0.01925`、`0.022`。配置文件中的旧 `size` 数值继续可读，但会吸附到最近的合法档位，保证运行时不会出现第六种尺寸。

## 成长行为

- 只在当前拖放批次由 Windows Shell 确认成功回收后增加累计数；失败、取消、过期批次不计数。
- 一个文件夹按一个顶层项目计算，不递归统计内部内容。
- 累计数最大为 `10`，超过后保持最大档。
- 达到新档位时，以 smoothstep 缓动在 `0.4` 秒内从当前显示半径平滑过渡到目标半径。
- 一次回收跨过多个阈值时，只播放一次动画并直接到最终档位。
- 动画只改变黑洞半径；现有中心位置、拖放命中、鼠标引力、预设外观和捕获流程保持不变。依赖半径的拖放命中与鼠标引力会随动画后的当前显示半径同步更新。

## 手动选档

托盘大小菜单提供且只提供上述五档。手动选档会：

1. 将累计吞噬进度同步到该档的阈值 `0/1/3/5/10`；
2. 用同样的 `0.4` 秒动画切换尺寸；
3. 让后续成功吞噬从这个手动档位继续累计成长。

因此菜单勾选、累计进度和目标尺寸始终一致。配置文件热重载的 `size` 也按最近档同步这三者。

## 托盘汉化

所有用户可见托盘文字改为简体中文，包括：

- 八个外观预设名称；
- 大小、速度、帧率、屏保、旋转、位置、显示器等菜单及其选项；
- 打开配置文件、退出、更新提示；
- 托盘悬停提示。

内部配置键、预设键和程序名称保持不变，避免破坏已有配置。

## 验证

- 单元测试覆盖累计数的每个阈值边界、`10` 的上限和每档半径。
- 单元测试覆盖旧配置尺寸吸附、手动档位同步和 `0.4` 秒动画的起点、中点、终点。
- 单元测试断言五个大小档及其他托盘标签均为中文。
- 完整执行格式检查、所有测试、所有目标检查、着色器验证和 Release 构建。
