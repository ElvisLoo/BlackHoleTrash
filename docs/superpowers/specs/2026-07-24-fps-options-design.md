# 30/60 帧率选项设计

## 目标

Black Hole Trash 的帧率只允许 `30` 和 `60` 两档。托盘不再显示“不限帧率”，配置文件中的 `fps = 0` 及其他数值也不再启用无限帧率。

## 行为

- 默认帧率为 `60`。
- 托盘“帧率”子菜单只有“30 帧”和“60 帧”，默认勾选“60 帧”。
- 配置文件只接受精确的 `fps = 30` 或 `fps = 60`。
- `fps` 缺失、等于 `0` 或为其他数值时统一使用 `60`。
- 启动读取和配置热重载使用同一个规范化函数；热重载后同步托盘勾选。
- 帧调度始终走有限帧率路径，删除 `fps == 0` 的无限轮询分支。

## 兼容性

配置键名 `fps` 保持不变。旧配置中的 `fps = 0` 无需迁移文件，运行时自动回退到 `60`。其他外观、成长、回收、捕获和托盘选项不变。

## 验证

- 单元测试断言托盘只有 `30`、`60` 两项。
- 单元测试断言 `30` 保持为 `30`，`60` 保持为 `60`，缺失、`0` 和其他数值均回退为 `60`。
- 执行格式检查、全部测试、全部目标检查和 Release 构建。
